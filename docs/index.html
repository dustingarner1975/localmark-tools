Use LocalMark in your own project

Install the Python client

With Python 3.10 or newer installed, run this command in your terminal. It installs the localmark command and Python library. No API key is required.

python -m pip install https://localmark.ai/static/downloads/localmark_client-0.3.0-py3-none-any.whl

Find a capability shortlist with reasons and caveats, search using recent evidence, or check an address before your script connects:

localmark recommend "extract text from PDF documents" --card-hours 24 --tls
localmark search weather --card-hours 24 --a2a-hours 24 --tls
localmark verify agent.example.com/a2a
localmark gate agent.example.com/a2a --card-hours 24 --a2a-hours 24 --tls

agent.example.com is a placeholder: replace it with an agent’s real address. gate exits 0 when the requested stored evidence passes, 2 when it does not, and 1 on a request or input error. It does not execute a publisher’s task.
